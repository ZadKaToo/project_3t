                              เอกสารโครงร่างสถาปัตยกรรมและฟังก์ชันระบบ (System Architecture & Feature Specification)
                               ชื่อโครงการ: ระบบเกมตอบคำถามรูปแบบ D&D Turn-based RPG (Educational RPG Quiz Game)

1. ภาพรวมและสถาปัตยกรรมระบบ (System Overview & Architecture)การพัฒนาระบบนี้มุ่งเน้นการประยุกต์ใช้แนวคิด Gamification เพื่อเพิ่มความน่าสนใจในการทำแบบทดสอบ โดยแบ่งโครงสร้างทางสถาปัตยกรรมออกเป็นส่วนต่างๆ ดังนี้:

Frontend (ส่วนแสดงผลและส่วนโต้ตอบผู้ใช้งาน): * พัฒนาด้วย HTML, CSS, JavaScript เพื่อจัดการโครงสร้าง ความสวยงาม อนิเมชัน (เช่น การทอยลูกเต๋า, เอฟเฟกต์การต่อสู้) และการโต้ตอบของผู้ใช้งานบนหน้าเว็บ
-ใช้ EJS (Embedded JavaScript templating) ร่วมกับ Node.js ในการเรนเดอร์หน้าเว็บแบบไดนามิกและการเปลี่ยนหน้าจอ (Routing)

Web Server & Middleware (ส่วนจัดการการเชื่อมต่อ):
- ใช้ Node.js (Express.js) เป็นเซิร์ฟเวอร์หลักในการจัดการ Request/Response และเชื่อมต่อกับฐานข้อมูล
- ผสานการทำงานกับ Socket.io เพื่อรองรับฟังก์ชันการอัปเดตข้อมูลแบบเรียลไทม์ (Real-time Communication) ในอนาคต

Backend Logic (ส่วนประมวลผลตรรกะเกม): * ใช้ Python (ผ่านการสร้าง API) ในการจัดการตรรกะที่ซับซ้อนของเกม เช่น อัลกอริทึมการสุ่ม (RNG), การคำนวณความเสียหาย (Damage Calculation) และระบบสุ่มไอเทม (Loot Drop)

Database (ระบบฐานข้อมูล): * ใช้ MySQL สำหรับจัดเก็บข้อมูลระบบทั้งหมด โดยบริหารจัดการโครงสร้างและข้อมูลผ่านโปรแกรม DBeaver

Infrastructure (โครงสร้างพื้นฐาน):
- ใช้ Docker และ Docker Compose ในการทำ Containerization เพื่อให้ง่ายต่อการติดตั้งและควบคุมสภาพแวดล้อมของระบบ (Environment)

2. โครงสร้างฟังก์ชันการทำงาน (Core Features)ระบบได้ปรับเปลี่ยนรูปแบบการทำแบบทดสอบให้เป็นระบบเกม (Game Flow) โดยมีฟังก์ชันหลัก 7 ส่วน ดังนี้

2.1) ระบบจัดการผู้เล่นและหน้าต่างหลัก (Main Menu & Lobby):
  - รองรับการเข้าสู่ระบบ, เริ่มเกมใหม่, โหลดข้อมูลการเล่นเดิม และการแสดงผลกระดานผู้นำ (Leaderboard)
  - มีหน้าต่างระบบจัดการตัวละคร (Character Management) สำหรับตรวจสอบสถานะ (HP/MP/Gold) สวมใส่อุปกรณ์ และจัดการคลังไอเทม (Inventory)

2.2) ระบบการเดินทางและสุ่มเหตุการณ์ (Dice Roll & Map Progression):
  - ใช้การทอยลูกเต๋าเพื่อกำหนดทิศทางการเคลื่อนที่และสุ่มสถานที่ (เช่น ป่า, เมือง, ดันเจี้ยนลับ) แทนการเลือกระดับความยากแบบดั้งเดิม โดยระดับความยากของคำถามจะอิงตามสถานที่หรือมอนสเตอร์ที่พบ

2.3) ระบบการต่อสู้แบบสลับตาและชุดคำถาม (Turn-based Combat & Quizzes):
  - เมื่อผู้เล่นเผชิญหน้ากับศัตรู ระบบจะดึงชุดคำถามจากฐานข้อมูลมาแสดง
  - ผู้เล่นจำเป็นต้องตอบคำถามให้ถูกต้องเพื่อสร้างความเสียหาย (Attack) หรือป้องกัน (Defend) หากตอบผิดจะได้รับความเสียหายจากศัตรู

2.4) ระบบของรางวัลและไอเทม (Loot & Inventory System):
  - เมื่อเอาชนะศัตรูหรือผ่านเหตุการณ์สำเร็จ ระบบจะทำการสุ่มมอบของรางวัล เช่น สกุลเงินในเกม (Gold), ไอเทมฟื้นฟู (Potion), หรืออุปกรณ์สวมใส่ (Equipment) เพื่อเสริมค่าสถานะตัวละคร

2.5) ระบบตัวช่วยพิเศษ (Skills & Helper Items):
  - ประยุกต์ระบบคำใบ้ (Hint) เป็นการใช้ "ทักษะ" หรือ "ไอเทม" เช่น ไอเทมตัดตัวเลือกที่ผิด, หรือทักษะป้องกันความเสียหายจากการตอบผิด 1 ครั้ง โดยผู้เล่นต้องใช้ทรัพยากร (Gold/Item) ในการเปิดใช้งาน

2.6) ระบบการต่อสู้ระดับบอส (Final Boss Battle):
  - เมื่อผู้เล่นดำเนินเกมถึงเงื่อนไขที่กำหนด (เช่น จำนวนรอบการทอยลูกเต๋า หรือเก็บไอเทมเควสต์ครบ) ระบบจะบังคับเข้าสู่การต่อสู้ระดับสูงสุด
  - ชุดคำถามจะมีความยากระดับสูงสุด ซึ่งผู้เล่นต้องบริหารจัดการไอเทมและอุปกรณ์ที่สะสมมาเพื่อผ่านด่าน

2.7) ระบบสรุปผลและฉากจบ (Summary & Ending):
  - Victory/Game Over: แสดงฉากจบที่แตกต่างกันตามผลลัพธ์การเล่น
  - Result Screen: สรุปคะแนนรวม (Score/EXP), สถิติการตอบคำถาม (ถูก/ผิด), และบันทึกข้อมูลประวัติการเล่นลงในฐานข้อมูล

                                         3. โครงสร้างฐานข้อมูลเบื้องต้น (Database Schema Draft)
ระบบฐานข้อมูล MySQL ได้รับการออกแบบตาราง (Tables) เบื้องต้นเพื่อรองรับระบบเกม ดังนี้:
                          ชื่อตาราง (Table Name)                                          คำอธิบายและหน้าที่หลัก (Description)

                               Players                                      เก็บข้อมูลส่วนตัวและสถานะของผู้เล่น (Player ID, Username, HP, Gold, ด่านปัจจุบัน)              
                              Questions                                     เก็บข้อมูลชุดข้อสอบ (Question ID, สถานที่/หมวดหมู่, โจทย์, ตัวเลือก A-D, เฉลย)           
                                Items                                    เก็บฐานข้อมูลไอเทมทั้งหมดในเกม (Item ID, ชื่อไอเทม, ประเภท [เกราะ/ยา/อาวุธ], ค่าเอฟเฟกต์)
                              Inventory                                      เก็บข้อมูลการครอบครองไอเทมของผู้เล่น (Player ID, Item ID, จำนวนที่ครอบครอง)
                               History                                    เก็บประวัติและสถิติการเล่นเพื่อนำไปประมวลผล (Player ID, คะแนนที่ได้, จำนวนข้อที่ตอบถูก/ผิด)

                                           4. โครงสร้างการตั้งค่าเซิร์ฟเวอร์ (Containerization Setup)
              ระบบรันผ่าน Docker เพื่อจำลองสภาพแวดล้อมของ Web Application (Node.js) และ Database (MySQL) ตามโครงสร้างไฟล์ดังนี้:

4.1 Web Server (Dockerfile)
กำหนดสภาพแวดล้อมสำหรับ Node.js โดยติดตั้งไลบรารีที่จำเป็น รวมถึง EJS สำหรับแสดงผลและ Socket.io สำหรับการสื่อสารข้อมูลDockerfile# ใช้ Node.js เป็น Base Image

Dockerfile
--------------------------------------------------------------------------
FROM node:18-alpine
# กำหนดพื้นที่ทำงาน
WORKDIR /usr/src/app
# ติดตั้ง Dependencies ที่จำเป็น
RUN npm init -y && npm install express mysql2 ejs express-session socket.io
# คัดลอก Source Code
COPY . .
# เปิด Port 80 สำหรับการเชื่อมต่อ
EXPOSE 80
# คำสั่งรันเซิร์ฟเวอร์
CMD ["node", "server.js"]
---------------------------------------------------------------------------

4.2 Infrastructure (docker-compose.yml)จัดการการเชื่อมต่อระหว่าง Web Application และ MySQL DatabaseYAMLservices:
---------------------------------------------------------------------------
YAML
  db:
    image: mysql:8.0
    container_name: mysql_db
    command: --default-authentication-plugin=mysql_native_password
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: root_password
      MYSQL_DATABASE: my_web_db
      MYSQL_ROOT_HOST: '%' 
    ports:
      - "3306:3306"
  
  app:
    build: .
    container_name: web_app
    ports:
      - "8080:80"
    depends_on:
      - db
---------------------------------------------------------------------------
